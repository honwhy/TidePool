Spring Boot 集成

Starter 面向 Spring Boot 3.x（Java 17+），提供自动配置、spring.tidepool.ftp.* 属性绑定、Actuator 健康检查与条件化 JMX。

1. 引入 Starter

<dependency>
    <groupId>io.ftppool</groupId>
    <artifactId>ftp-pool-spring-boot-starter</artifactId>
    <version>0.1.0-SNAPSHOT</version>
</dependency>

Starter 会传递引入：ftp-pool-adapter、ftp-pool-engine-fast、ftp-pool-observability、 ftp-pool-micrometer、ftp-pool-jmx 与 Spring Boot starter。使用 commons 引擎时需再显式加入 ftp-pool-engine-commons。

2. 最小配置

spring:
  tidepool:
    ftp:
      host: ftp.example.com
      port: 21
      username: user
      password: ${FTP_PASSWORD}

spring.tidepool.ftp.enabled 默认为 true。若开启但未配置 spring.tidepool.ftp.host，应用启动会失败并提示： spring.tidepool.ftp.enabled=true but spring.tidepool.ftp.host is not configured。要禁用请显式设置 spring.tidepool.ftp.enabled=false。

4. 注入使用

@Service
public class ReportService {

    private final FtpClientTemplate ftp;

    public ReportService(FtpClientTemplate ftp) {   // 也可注入 FtpPool
        this.ftp = ftp;
    }

    public void upload(InputStream in) throws FtpException {
        ftp.upload("/data/report.csv", in);
    }

    public FtpPoolStats stats() {
        return ftp.stats();
    }
}

5. mode 与逐轴覆盖

spring.tidepool.ftp.pool.mode 对应 FtpPoolProfiles 预设（默认 hybrid）：

spring:
  tidepool:
    ftp:
      pool:
        mode: hybrid          # fast | commons | monitor | hybrid
        engine: FAST          # 可选：逐轴覆盖，缺省用 mode 预设
        lifecycle: COMMONS
        observability: FULL
modeenginelifecycleobservability
hybrid（默认）FASTCOMMONSFULL
fastFASTSIMPLENONE
commonsCOMMONSCOMMONSNONE
monitorFASTSIMPLEFULL

6. 可观测性属性

spring:
  tidepool:
    ftp:
      observability:
        enabled: true                 # 过滤链总开关
        metrics: true                 # 存在 MeterRegistry 时接入 Micrometer，否则用内置计数器
        jmx: true                     # 注册 JMX MBean
        slow-operation-threshold: 3s  # 慢操作阈值

Spring 场景下由容器组装过滤链：MetricsFilter（接入 Micrometer）、审计用 LoggingFilter、SlowOperationFilter。 当 mode 为 fast/commons 且未显式覆盖 observability 时，过滤链为空。

JMX MBean 对象名：com.ftppool:type=FtpPool,name=<poolName>。 指标名与 JMX 属性详见 可观测性。

7. Actuator 健康检查

存在 Actuator 时，健康端点下会出现 ftpPool 贡献者：

{
  "status": "UP",
  "details": {
    "ftpPool": { "total": 10, "active": 3, "idle": 7, "pending": 0 }
  }
}
状态含义
UP池可用。惰性空池也是健康的——它按需创建；瞬时打满但没有等待者同样健康。
DEGRADED当前确有争用：此刻有 borrower 在等待连接（pending > 0）。
DOWN池已关闭，无法再服务。

健康检查反映实时状态，不使用历史累计计数——曾发生过一次 borrow 超时不会让池永久停在 DEGRADED。

8. 覆盖与定制

  • 自定义 Pool：自行声明 FtpPool Bean 即可接管，自动配置会退让（@ConditionalOnMissingBean）。
  • 自定义 TLS：声明一个 SSLContext Bean，自动配置会将其用于 FtpSslConfig。
  • 关闭 JMX：设置 spring.tidepool.ftp.observability.jmx=false。
  • 关闭可观测性：设置 spring.tidepool.ftp.observability.enabled=false。
