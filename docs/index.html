30 秒示例

FtpPool pool = FtpPoolProfiles.hybrid()          // 默认推荐：Fast 引擎 + 完整生命周期 + 可观测
        .host("ftp.example.com")
        .port(21)
        .username("user")
        .password(System.getenv("FTP_PASSWORD")) // 密码绝不写进日志 / 指标 / JMX
        .build();

try (pool) {
    boolean ok = pool.execute(ftp ->
            ftp.upload("/data/report.csv", inputStream));
}

execute() 一行完成 borrow → 执行 → 校验 → 归还； 连接类异常自动销毁，业务异常安全回池，无需手工 release。

核心特性

能力说明
真正的连接池借出 / 归还、空闲与最大寿命回收、并发建连节流、优雅关闭 drain。
有状态连接重置归还时重置工作目录、文件类型（BINARY）、被动模式、编码；重置失败即销毁，绝不带脏状态回池。
FTP + FTPS明文 FTP、Explicit FTPS、Implicit FTPS；TLS 校验默认开启，trust-all 必须显式开启且标记不安全。
三轴可组合引擎（Fast / Commons）、生命周期（SIMPLE / COMMONS）、可观测性（NONE / BASIC / FULL）相互独立。
生产可观测逐操作指标与字节数、JMX MBean、Micrometer、慢操作告警、连接泄漏检测、实时健康语义。
Spring Boot 3Starter 自动配置、ftp.* 属性绑定、Actuator 健康检查、条件化 JMX。

Profile 预设（怎么选）

Profile引擎生命周期可观测性适用
hybrid() 默认FastCOMMONSFULL生产推荐
fast()FastSIMPLENONE极致低延迟、无后台维护
commons()CommonsCOMMONSNONE以 Commons Pool 生命周期为先
monitor()FastSIMPLEFULL只想要监控、不要后台维护

入口类：io.ftppool.core.FtpPoolProfiles。也可用 FtpPoolBuilder.builder() 逐轴配置，详见 配置参数。
